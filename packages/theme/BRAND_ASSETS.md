# Official SUGAT assets

The supplied authoritative raster is stored at `packages/theme/assets/sugat-logo-official.png` and copied unchanged into each client that consumes it. Preserve its aspect ratio and do not recolor or redraw it.

For final store production, request these approved source exports from the brand owner:

- `packages/theme/assets/sugat-logo-full.svg` — full-color horizontal logo for light web surfaces
- `packages/theme/assets/sugat-logo-white.svg` — approved reversed logo for navy web heroes
- `packages/theme/assets/sugat-logo-navy.svg` — approved one-color logo
- `packages/theme/assets/icon-1024.png` — square mobile store icon
- `packages/theme/assets/adaptive-icon-foreground.png` — transparent Android adaptive foreground
- `packages/theme/assets/splash-logo.png` — transparent approved splash mark
- `packages/theme/assets/favicon.svg` — approved browser favicon

The current raster is configured for mobile icons, splash screens, web favicons, headers, and heroes. Purpose-built transparent and square exports remain preferable because the supplied board is rectangular and includes substantial white space.
